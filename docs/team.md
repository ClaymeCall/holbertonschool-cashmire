## Working agreement

- **Meetings:** short daily stand-up (15 min); weekly sync to review progress and plan the next week.
- **Communication channel:** team chat for day-to-day discussion; GitHub issues and PR comments for anything tied to code.
- **Blockers:** post in the team chat as soon as blocked, tag the issue owner or the relevant member, and comment on the GitHub issue. If unresolved by the next stand-up, it is discussed there and reassigned if needed.
- **Scope:** each member works on their own issues; changes outside your ownership are agreed with the owner first.
- **Pull requests:** every change goes through a PR reviewed by at least one other member before merging.
