## Accord de travail

> Les éléments marqués **(proposition)** sont à confirmer par l'équipe.

### Cadence des réunions

- Projet de 4 jours : un point court d'équipe synchrone (~10 min) chaque matin : avancement, blocages, priorités du jour.
- Un point de synchronisation en fin de journée, si nécessaire.
- Une revue d'équipe le dernier jour, avant la présentation.
- Jours et horaires : tous les jours 9h et 16h30

### Canal de communication

- *Un canal de discussion d'équipe unique pour les échanges quotidiens : Discord.
- Les décisions techniques et les questions liées à du code passent par les issues et pull requests GitHub, pour garder une trace.

### Remontée des blocages

1. Dès qu'un membre est bloqué, il le signale sans attendre le prochain point, dans le canal d'équipe.
2. Le message indique : l'issue concernée, ce qui bloque, ce qui a déjà été essayé.
3. Si le blocage dépend d'un autre domaine, le propriétaire du domaine (voir tableau) est sollicité en priorité.
4. Un blocage non résolu sous 1 h est traité immédiatement en appel, sans attendre le point suivant.
5. Le blocage est consigné en commentaire de l'issue concernée.
